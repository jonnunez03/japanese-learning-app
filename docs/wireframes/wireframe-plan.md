# Wireframe Plan

## Target Screen Sizes

- Mobile: 390px
- Tablet: 768px
- Desktop: 1440px
- Desktop content max-width: 1200px

## Initial Screens

### 1. Dashboard
Purpose:
Give the learner an overview of their progress and quick access to lessons.

Main content:
- Continue lesson
- Vocabulary progress
- Hiragana progress
- Katakana progress
- Grammar progress
- Review button
- Learn button

### 2. Vocabulary
Purpose:
Teach individual Japanese words and track whether the learner knows them.

Main content:
- Kana
- Kanji
- English meaning
- Audio button
- Romaji toggle
- Kanji display setting
- Known / learning status
- Practice button

### 3. Sentence Builder
Purpose:
Teach Japanese sentence structure using words the learner already knows.

Main content:
- English prompt
- Japanese word choices
- Sentence-building area
- Check answer button
- Grammar explanation
- Word and particle explanations

### 4. Word Forms
Purpose:
Teach learners how known verbs and adjectives change depending on usage.

Main content:
- Base word
- Meaning
- Requested form
- Answer choices or text input
- Explanation after answering

Examples:
- Non-past
- Past
- Negative
- Past negative
- Polite
- Te-form
