# User Flow

## New User

1. User creates an account or signs in.
2. User chooses reading preferences:
   - Kana First
   - Adaptive
   - Full Japanese
3. User chooses whether romaji is shown.
4. User begins learning hiragana, katakana, vocabulary, and grammar.
5. The app records progress for future lessons.

## Returning User

1. User signs in.
2. Dashboard loads saved progress.
3. App shows:
   - Continue lesson
   - Reviews due
   - Vocabulary progress
   - Kana progress
   - Grammar progress
4. User selects a learning activity.

## Vocabulary Flow

1. App selects a word.
2. Word is displayed using the user's reading preferences.
3. User can listen to Japanese pronunciation.
4. User attempts to recall the meaning.
5. User reveals the meaning if needed.
6. User marks the word as:
   - Known
   - Still learning
7. App updates the user's word progress.

## Sentence Builder Flow

1. App selects vocabulary the user already knows.
2. App chooses a grammar concept to practice.
3. User receives a sentence prompt.
4. User arranges Japanese words and particles.
5. User checks the answer.
6. App displays feedback.
7. App explains the sentence structure.
8. Progress is saved.

## Word Forms Flow

1. App selects a known verb or adjective.
2. App requests a specific form.

Examples:
- Plain
- Polite
- Past
- Negative
- Past negative
- Te-form

3. User chooses or enters the correct form.
4. App checks the answer.
5. App explains the transformation rule.
6. User progress is updated.

## Review Flow

1. App finds vocabulary, kana, grammar, or word forms that need review.
2. Weak or overdue material is prioritized.
3. User completes review exercises.
4. Review performance updates future lesson selection.
